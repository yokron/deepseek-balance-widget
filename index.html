DeepSeek 余额小组件 Scriptable

iPhone 桌面看 DeepSeek 账户余额 · 赠金/充值 · 累计消费直方图 · 离线缓存

① 复制脚本

  1. 点下面 「复制脚本」（没反应就点「全选」再点弹出的「拷贝」）
  2. 打开 Scriptable → 右上角 + 新建脚本
  3. 编辑区 长按 → 粘贴 → 左上角改名 DeepSeek 余额
  4. 点 ▶️ 运行 → 选 设置 API Key → 粘贴 sk-...（存本机钥匙串）
下载 .js

② 加到桌面

  1. 回主屏 → 长按空白处 → 左上角 + → 搜索 Scriptable
  2. 选尺寸（小 / 中 / 大）→ 添加小组件
  3. 长按该组件 → 编辑小组件 → Script 选 DeepSeek 余额
  4. Parameter 可留空，或填 work、work|USD 指定别名 / 主货币，末尾加 line 把直方图换成折线
iOS 不允许小组件实时刷新，系统大约 15 分钟 ~ 1 小时重跑一次，属正常。
